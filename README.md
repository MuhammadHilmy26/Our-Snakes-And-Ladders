# 🐍 Our Snakes And Ladders (Couple Edition)

Game Ular Tangga interaktif berbasis web yang dirancang khusus untuk dimainkan berdua bersama pasangan. Dilengkapi dengan berbagai tantangan seru di setiap kotaknya!

## 🚀 Fitur Utama
- **Multiplayer Lokal (2 Pemain):** Main bergantian dengan kustomisasi nama pemain (Player 1 & Player 2).
- **Pilihan Ukuran Papan:** Bisa memilih ukuran papan yang diinginkan (30, 45, 60, hingga 100 kotak).
- **Tantangan Romantis/Interaktif:** Kotak-kotak tertentu memiliki label tantangan seru untuk dicoba bersama pasangan.
- **Ular & Tangga Dinamis:** Papan digenerate secara otomatis dengan posisi ular dan tangga yang bervariasi di setiap permainan baru.
- **Tampilan Responsif:** Nyaman dimainkan di perangkat desktop maupun *mobile*.

## 🛠️ Teknologi yang Digunakan
- **HTML5 / CSS3**
- **JavaScript (Vanilla)**
- **Tailwind CSS** (via CDN)

## 🕹️ Cara Memainkan
1. Clone atau download repositori ini ke komputer Anda.
2. Pastikan struktur folder gambar (`images/`) lengkap sesuai dengan kebutuhan game.
3. Buka file `ular_tangga_gua_premium.html` (atau ubah namanya menjadi `index.html`) langsung melalui browser web favorit Anda (Google Chrome, Mozilla Firefox, dll).
4. Masukkan nama pemain, pilih ukuran papan, lalu tekan **Mulai Bermain!**
